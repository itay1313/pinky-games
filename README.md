# Pinky 🎀 Online Games

פורטל משחקים אונליין לכל המשפחה — משחקים רצים ישירות בתוך האתר (iframe), בחינם ובלי התקנות.

## המשחקים
| משחק | גיל | קטגוריות |
|------|-----|-----------|
| 💩 פלופ! צלילה אל הביוב | 6+ | ארקייד, הרפתקה |
| 🦁 גן החיות של נלי | 2+ | חיות, למידה |

## פיצ'רים
- ▶️ משחק בתוך האתר במסך מלא (iframe player) עם חזרה ופתיחה בטאב
- 🧸 סינון לפי גיל (פעוטות / ילדים / נוער / כולם)
- 🏷️ סינון לפי קטגוריות + חיפוש חופשי
- 💗 מועדפים ו-🕘 "שיחקתם לאחרונה" (נשמרים במכשיר)
- 📱 רספונסיבי, עברית RTL, עיצוב bubblegum

## הוספת משחק חדש
מוסיפים אובייקט אחד ל-[games.js](games.js) — זהו. אם המשחק חוסם iframe, מסמנים `embed: false` והוא ייפתח בטאב חדש.

> חשוב: משחק שמוטמע חייב להתיר framing (בלי `X-Frame-Options: DENY` / `frame-ancestors 'none'`).

## הרצה מקומית
```bash
npx serve .
```
